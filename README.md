# AI520-TeamProject

Team Members: Sumit K C, Divakar Reddy Ravi & Thao H. B. Bui

Our team project evaluates the performance of three popular language models including BERT, RoBERTa and BART in classifying sentiment within social media data. We conducted a comparative analysis of these models using popular public data sources includingSemEval-2017 Task 4 (Rosenthal et al., 2017) dataset and Yelp Review Dataset to evaluate the accuracy, generalization capabilities, and overall performance of each model.
